☁️ Sinkronisasi Cloud (Supabase)

Simpan semua transaksi ke database Supabase supaya laporan bisa diakses dari mana saja dan tidak hilang kalau browser dibersihkan. Aplikasi tetap jalan normal tanpa ini.

Cara setup Supabase (sekali saja)
  1. Buat akun gratis di supabase.com → New Project
  2. Di project: buka SQL Editor → paste SQL di bawah → Run
  3. Buka Settings → API: salin Project URL dan anon public key ke kolom di atas → Simpan & Tes
  4. Untuk lihat/export laporan: buka Table Editor → pos_transactions di dashboard Supabase (bisa export CSV dari sana)

⚠️ Anon key ini memberi akses baca/tulis tabel transaksi — jangan bagikan link aplikasi + key ke orang luar.
