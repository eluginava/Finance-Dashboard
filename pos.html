☁️ Sinkronisasi Cloud (Supabase)

Simpan semua transaksi ke database Supabase supaya laporan bisa diakses dari mana saja dan tidak hilang kalau browser dibersihkan. Aplikasi tetap jalan normal tanpa ini.

🏬 Cabang perangkat ini: —
Produk, stok, dan laporan cabang ini terpisah dari cabang lain walau memakai satu Supabase.
🏬 Skema multi-toko (untuk fitur login & master produk)

Skema ini membuat tabel stores, users, categories, products, product_variants, store_products, customers, shifts, transactions, cash_movements, activity_log, vouchers sekaligus memindahkan data lama (produk, harga & stok per cabang, transaksi, dan member) ke struktur baru. Tabel lama tidak dihapus, jadi tetap ada cadangan. Aman dijalankan ulang.

Jalankan di Supabase → SQL Editor → Run. Setelah itu akan ada user awal: owner, serta manager-<kode> dan kasir-<kode> untuk tiap cabang — semuanya PIN 1234 dan wajib diganti setelah login pertama.

Cara setup Supabase (sekali saja)
  1. Buat akun gratis di supabase.com → New Project
  2. Di project: buka SQL Editor → New query → paste SQL di bawah seluruhnya → Run. Jangan dijalankan sepotong-sepotong: SQL Editor membungkus satu skrip dalam satu transaksi, jadi menjalankan sebagian akan gagal dan membatalkan semuanya.
  3. Buka Settings → API: salin Project URL dan anon public key ke kolom di atas → Simpan & Tes
  4. Untuk lihat/export laporan: buka Table Editor → pos_transactions di dashboard Supabase (bisa export CSV dari sana)

SQL di bawah hanya menyiapkan tabel transaksi & produk — cukup untuk sinkron penjualan. Untuk fitur multi-toko penuh (akun user, master produk, varian, member), jalankan supabase-schema.sql yang ada di folder aplikasi; file itu sudah mencakup semua yang di bawah ini.

⚠️ Anon key ini memberi akses baca/tulis tabel transaksi — jangan bagikan link aplikasi + key ke orang luar.
